# MH Comic Reader (Tauri Desktop) v0.3.1

A local comic reader with a light lavender theme: home (welcome banner + drag & drop import + recently read), shelf, local import, and settings. Built with Tauri 2 + Rust + vanilla HTML/JS.

[中文说明](README.md)

## Features

- **Three import types**: ZIP / CBZ archives, folders, loose images — or just drag files into the window
- **Streaming ZIP reading**: only the central directory is read; Rust extracts pages on demand into a cache, so even huge archives open without eating RAM
- **SQLite local shelf**: stores paths only, never copies your files; cover = first image in reading order
- **Auto resume**: reading progress saved every 4 seconds
- **Shelf folders**: create / rename / delete folders, move books between them
- **Themes**: 5 presets + custom color picker + replaceable home banner
- **Reading settings**: default vertical-scroll / page-turn mode, memory-saver toggle
- **Portable data dir**: database lives next to the executable by default, changeable in settings
- Everything stays local — no network, no uploads

## Build & Run

**Windows** (tested platform):

1. Install Rust (`rustup-init.exe` from https://rustup.rs), Node.js LTS, and VS Build Tools (Desktop development with C++). Windows 10/11 ships WebView2.
2. Unzip/clone anywhere (files sit at the root, no extra nesting), then in the project root:
   ```
   python scripts/gen-icons.py   # generate app icons (once)
   npm install    # first time only
   npm run build
   ```
3. After building, the binary is copied to the project root (`mh-reader.exe`) — double-click it. You only need to rebuild after code changes.

**macOS / Linux**: should work via `npm run build` (Tauri targets), but not yet tested — contributions welcome.

## Project Layout

```
mh-reader/
  mh-reader.exe        # copied here after build (Windows); double-click to run
  mh-reader.db         # shelf database (next to the exe by default)
  page_cache/          # per-page ZIP extraction cache
  data-dir.txt         # only present when a custom data dir is set
  src/
    index.html         # shelf home (home / shelf / import / settings; banner inlined as data URI)
    reader.html        # reader page
    reader-boot.js     # reader bootstrap: loads from shelf, applies config
    mh-common.js       # shared lib (invoke wrapper, fuzzy filename sort, cover gen)
  src-tauri/
    tauri.conf.json
    src/main.rs        # Rust commands: file dialogs / streaming ZIP / SQLite shelf / window controls
    icons/             # generated by scripts/gen-icons.py (not in repo)
  scripts/
    copy-exe.cjs       # copies the built binary to the project root
    gen-icons.py       # generates app icons
```

## Notes

- First build downloads Rust dependencies and takes a few minutes.
- RAR / 7z are not supported yet — extract to a folder first.
- Frameless window: custom — ▢ ✕ buttons in the title bar; drag empty areas to move.
