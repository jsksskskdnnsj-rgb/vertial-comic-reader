# v0.4 设计与实现稿（Claude 代问产出）

2026-10-20～21 由 Claude（网页版）在代问对话中产出，按一张浅紫薰衣草风的 UI 参考图驱动设计。本目录是三批产出的**累积最新版合并**（同名文件以最后一批为准），原样存档，尚未集成进 `src/` 现行应用。

## 文件清单

| 文件 | 内容 |
|---|---|
| `mh-ui.css` / `icons.svg` | 设计系统（色板取自参考图，主紫 #7C6CEB）与图标集 |
| `home.html` / `home.js` | 首页：侧栏 + 横幅 + 拖拽导入区 + 快速开始 + 最近阅读/最近添加，均已接后端命令 |
| `reader.html` / `reader-boot.js` / `reader.js` / `layout.js` | 阅读页：悬浮顶/底栏、进度条缩略图预览、快速设置；（page, frac）位置模型 |
| `shell.js` | 共享外壳：无边框窗口控制、中英双语字典（默认中文）、主题 |
| `chapters.js` / `chapter-settings.html` | 分话三模式：不分话 / 按文件夹 / 自定义每话页数（虚拟切分、即时重算） |
| `bookmarks.js` | 书签锚定到具体图片（ZIP 条目全名 / 相对路径 + 图内偏移），条目缺失标 broken |
| `cover_protocol.rs` | 列表封面：240px 封面图经 `mhcover` 自定义协议供图 |
| `reader_backend.rs` | 后端累积版（74 KB）：导入/打开/进度/分话/书签命令与表结构 |

## 状态与注意

- 书架 / 导入 / 设置三个页面尚未建（导航链接已留）。
- 与参考图的两处差异（作者在代码注释中写明）：右下“推荐漫画”改为“最近添加”（离线应用无推荐源）；横幅与侧栏插图为占位，自备图片放 `assets/`，缺失时退化为渐变。
